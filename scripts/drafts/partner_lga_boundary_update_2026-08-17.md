**Update: LGA boundary file added, and the monitoring dashboard is now live**

Two updates to share:

1. **LGA boundary file added to your package.** We've added a new file to your partner
folder — **`LGA_boundaries.kml`** — showing the outline of every LGA you're covering,
plus an updated **`How_To_Use_This_Package.pdf`** (v1.4) explaining how to use it.
Loading this alongside your sample points in Maps.me lets your team visually confirm a
point's GPS location genuinely falls within its assigned LGA, which should help resolve
the kind of "is this point in the right place?" questions some teams have already
raised. If a point ever looks like it's sitting outside the boundary line, please flag
it to your focal point rather than resampling — it's usually a display/projection issue
rather than an actual location error, and we can help confirm either way.

2. **The monitoring dashboard is now live with real data**, and accessible to everyone:
[https://impact-nga-jp.shinyapps.io/dashboard_app/](https://impact-nga-jp.shinyapps.io/dashboard_app/).
Use it to monitor data coverage and quality as collection progresses — it refreshes with
the latest data daily at **6pm Nigeria time**, so it's worth checking in on regularly
rather than just once.
